# 坦克大战 · Tank Battle

一个纯 HTML5 + Canvas 实现的经典坦克大战小游戏，单文件、零依赖，打开即玩。

## 玩法

- 操控你的坦克，消灭每一关出现的所有敌方坦克。
- **守住基地**（屏幕底部中央的旗帜）—— 基地被击毁则游戏结束。
- 每过一关敌人会更多、更快、更强，还有需要两炮才能击毁的装甲坦克。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W A S D` 或方向键（触屏可用虚拟摇杆） |
| 开火 | `空格` / `J` |
| 暂停 / 继续 | `P` / `Esc` |
| 开始 / 重开 | `Enter` |

## 特性

- 三类敌人：普通、快速、装甲（2 点生命）
- 可破坏的砖墙、不可破坏的钢墙
- 补给道具：护盾、加速射击、额外生命
- 得分 / 关卡 / 生命 HUD，逐关难度递增
- 音效（Web Audio API），可静音
- 支持键盘与移动端触屏

## 运行

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。

也可以通过 GitHub Pages 在线游玩（在本仓库启用 Pages 后）。
